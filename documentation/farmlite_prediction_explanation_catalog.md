# FarmLite Prediction Explanation and Safety Catalog

## Usage

Phase 5 may reference these stable message IDs in API responses. Frontend and
PDF wording are not changed in Phase 4.5E. Messages must be selected from
actual eligibility, source, and value-ownership metadata—never from a generic
success state.

| Message ID | Trigger | Proposed user-facing text | Severity |
|---|---|---|---|
| `BD_RESEARCH_SCOPE` | Any Bangladesh candidate output | Prediction based on Bangladesh HF-cross research data from 50 lactating cows. | Warning |
| `BD_TWO_FEATURE_MODEL` | Any Bangladesh candidate output | This prediction uses genetic group and heat-stress category; it does not model individual ration, body weight, lactation stage, or prior yield. | Information |
| `BD_CANDIDATE_ONLY` | Any Bangladesh candidate output | This model remains candidate-only and is not approved for production, commercial, or veterinary use. | Warning |
| `BD_DMI_DRY_MATTER` | DMI value present | This output estimates dry-matter intake in kg per cow per day, not total fresh-feed weight. | Warning |
| `BD_MILK_DAILY` | Bangladesh milk present | This output estimates milk yield in litres per cow per day for the study target. | Information |
| `BD_RULE_OWNERSHIP` | Any rule recommendation shown with ML | Feed composition and advisory quantities are generated by nutrition rules, not by the Bangladesh ML model. | Information |
| `BD_NO_RATION_LABELS` | DMI or rule outputs shown | The study did not provide expert feed types, ration ingredients, roughage, concentrate, mineral, or water recommendation labels. | Warning |
| `BD_LOCAL_LIMITED` | `genetic_group=Local` | The Local category was used during development but had no cow in the locked final holdout; support is limited. | Warning |
| `BD_ENVIRONMENT_LIMIT` | THI calculated | THI was calculated from the entered temperature and humidity, but the study workbooks did not contain numeric weather values for distribution comparison. | Warning |
| `BD_EXTERNAL_VALIDATION_MISSING` | Any Bangladesh candidate output | This candidate has not been validated on an independent farm or FarmLite population. | Warning |
| `PREDICTION_OUT_OF_SCOPE` | Scope result `OUT_OF_SCOPE` | Prediction unavailable because the cow is outside the model's documented population scope. | Error |
| `GENETIC_GROUP_MISSING` | Missing genetic group | Bangladesh prediction unavailable because an exact documented genetic group was not supplied. Breed was not used as a substitute. | Error |
| `GENETIC_GROUP_UNKNOWN` | Unsupported category | Bangladesh prediction unavailable because the genetic group is not supported by the candidate. | Error |
| `ENVIRONMENT_MISSING` | Temperature or humidity missing | Bangladesh prediction unavailable because measured temperature and humidity are required to calculate the heat-stress category. | Error |
| `ENVIRONMENT_INVALID` | Invalid temperature/humidity/calculation | Bangladesh prediction unavailable because the environmental input is invalid. | Error |
| `ARTIFACT_UNAVAILABLE` | Artifact/metadata absent | Candidate prediction is temporarily unavailable because the reviewed model artifact could not be loaded. | Error |
| `ARTIFACT_HASH_MISMATCH` | Integrity check fails | Candidate prediction was refused because the model artifact failed its integrity check. | Error |
| `MODEL_ERROR` | Model returns error/non-finite output | Candidate prediction failed and was not used. Any fallback source is identified separately. | Error |
| `FALLBACK_USED` | Another source selected | The requested candidate was unavailable; FarmLite used the explicitly named fallback source. | Warning |
| `NO_DMI_FALLBACK` | DMI candidate ineligible and no approved rule | Dry-matter-intake prediction is unavailable; FarmLite did not substitute an unrelated feed-quantity model. | Warning |
| `HISTORICAL_MILK_NOT_PREDICTION` | User history used | The displayed milk value is user-provided historical information, not an ML prediction. | Information |
| `OUTCOME_RANGE_LIMIT` | Candidate output outside source target range | The prediction is outside the outcome range observed in the Bangladesh study and has limited support. | Warning |
| `ADVISORY_ONLY` | Any final recommendation | This is decision support and not veterinary or qualified animal-nutrition advice. | Warning |

## Required Composition Rules

- Always pair `BD_DMI_DRY_MATTER` with any displayed DMI value.
- Always pair `BD_RULE_OWNERSHIP` with rule outputs shown near ML outputs.
- Always pair `BD_RESEARCH_SCOPE`, `BD_CANDIDATE_ONLY`,
  `BD_EXTERNAL_VALIDATION_MISSING`, and `ADVISORY_ONLY` with an eligible
  Bangladesh prediction.
- Show the exact ineligibility message before `FALLBACK_USED`.
- Name the fallback model/rule/history source in structured metadata and
  nearby explanation.
- Never call a historical input, default, or rule output an ML prediction.
- Never suppress integrity or out-of-scope failures behind a generic warning.

## Display Priority

1. Integrity/model failure.
2. Out-of-scope or invalid input.
3. Fallback source.
4. Unit/material-basis warning.
5. Scope and external-validation limitations.
6. Advisory disclaimer.
